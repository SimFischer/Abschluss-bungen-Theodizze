## Auf GitHub Pages veröffentlichen

1. ZIP entpacken und ein öffentliches GitHub-Repository erstellen.
2. Über „Add file → Upload files“ alle drei Dateien (index.html, .nojekyll, README.md) direkt ins Hauptverzeichnis hochladen und committen. Nicht die ZIP oder einen übergeordneten Ordner hochladen.
3. Unter „Settings → Pages“ bei „Source“ die Option „Deploy from a branch“ auswählen.
4. Branch „main“ und Ordner „/(root)“ wählen und „Save“ anklicken.
5. Nach der Veröffentlichung steht der Link zur App unter „Settings → Pages“ bereit.

GitHub-Anleitung: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
